# Homepage sketches — overnight-unclone

Five full pages. Each keeps the matching header system from `sketches/overnight-unclone/header/`. Product stills are the existing files (CV2, CM2, SHZV, HWV, WSL, CMA7). Not wired into `src/`.

**01 — Compact bar + one still + type list.** A short title, one CV2 photograph, a fact list (Shanghai, Singapore, 4–6 weeks, PDFs), then six type lines. It still feels like a factory site because the page is a sheet: one object, then the list. It does not look like Reinhausen because there is no full-bleed slider, no three-column teaser, and no product carousel.

**02 — Navy bar + split first screen + grid.** Photo on the left, facts on the right, then a six-cell type grid with hairlines, not a slideshow. It still feels like a factory site because the first screen is a unit and a plate, not a campaign. It does not look like Reinhausen because the top is a painted navy bar and the types sit in a table-like grid, not a swiper.

**03 — Steel rail + catalog rows.** Title, a meta strip, then a table: type / kind / PDF. It still feels like a factory site because the homepage is the catalogue. It does not look like Reinhausen because there is no stage, no teaser-big, and no card deck; the steel rail is not their floating white utility row.

**04 — Left lockup + factory band + types.** Nameplate header, then Shanghai factory and Singapore HQ as two address blocks, then types with small stills. It still feels like a factory site because the middle of the page is where you write and where you ship from. It does not look like Reinhausen because the identity is a side lockup and the “hero” is an address band, not a gradient caption on a slider.

**05 — Ink bar + spec-first.** Lead time, factory, HQ, PDFs, mail as a definition list, then the six types as rows. It still feels like a factory site because numbers and documents come before mood. It does not look like Reinhausen because the header is an ink instrument strip and the page has no photography stage at all.
