# Audit — homepage sketches (cycle after Eric 2026-08-26 23:31)

Checked against: big 3:2 contain still first; type strip (CV2, CM2, SHZV, HWV, WSL, CMA7); news that is not MR chrome; no stretch; not a Reinhausen copy; a transformer buyer would trust it; PDFs, 4–6 weeks, Shanghai, Singapore.

## Verdict

Not all five fail. **Pick 02.** Runner-up **01**. Do not pick 03 if the lock on “product strip like MR homepage” is strict.

## File by file

**01 — Compact bar.** Pass. First screen is a large CV2 still, 3:2 contain, whole unit visible. Types are a six-up strip. News is a dated list, not a card carousel. Facts (PDF, 4–6 weeks, Singapore mail) sit next to the title. Looks like a factory catalogue, not reinhausen.com. Weakness: the title is under the photo, so the first screen is image-only until you scroll a little. Still usable.

**02 — Navy bar.** Pass. Best first screen: the still fills the navy field, contain, no cinema crop, no gradient caption on the tank. Data ribbon (lead time, PDF, mail) is on that same navy block. Type strip. Numbered news, not MR teaser tiles. Huaming navy, not MR gold. This is the one a buyer can screenshot and send to a colleague.

**03 — Steel rail.** Fail the strip lock. The types are a **table** (type / kind / PDF), not a homepage row of units. HWV still is large and unstretched. News is two titles, thin. A buyer would trust the table. Shiloh should not pick it if “strip/row of types” is non-negotiable.

**04 — Left lockup.** Borderline. It steals MR’s **order** (hero / types / news) on purpose. Chrome is not theirs (nameplate, no gold, no swiper). SHZV sits small in a tall 3:2 well — not stretched, but a lot of empty white, so the first image is big-frame, small-object. Type strip has names only, no kind line. Usable if Shiloh wants the MR rhythm without the MR clothes. Risky if “must not look like Reinhausen” is the loudest lock.

**05 — Ink bar.** Pass, with a caveat. Spec strip (4–6 weeks, Shanghai, Singapore, PDFs) is the most export-honest. Still is 3:2 contain on ink. Type row and two-line news work. Caveat: the inverted mark is tiny; some buyers will not read “Huaming” at a glance. Pick this only if facts-before-picture is the brief.

## Stretch check

All six stills in every file use `aspect-ratio: 3/2` and `object-fit: contain`. Files are 600×414 or 836×577 (~1.45). No cover crop, no 16:9 lie. Pass.

These are sketches. Inner product pages were not touched. The live `/` is still the old stage. Wiring 02 into `src/` is a later turn.
